Features an ultra-modern **Deep Obsidian Slate (`#060913`) + Electric Cyber Cyan (`#38bdf8`) + Neon Emerald (`#10b981`)** color scheme with custom volumetric overhead spotlight cones, frosted glassmorphism, responsive navigation dock, interactive command palette (`⌘K`), and hardware-accelerated **Three.js 3D interactive simulations** for each production-grade engineering project.

## ⚡ Quick Start

```bash
# Clone the repository
git clone https://github.com/amanraj2408/Portfolio.git

# Navigate into project
cd Portfolio

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Visit `http://localhost:3000` to view the application.

## 🌐 Deploy to Vercel

The easiest way to deploy this Next.js 16 portfolio is directly through Vercel:

1. Push this repository to your GitHub account (`amanraj2408/Portfolio`).
2. Go to [Vercel Dashboard](https://vercel.com/dashboard) and click **"Add New Project"**.
3. Import the `Portfolio` repository.
4. Leave the default build command (`npm run build`) and output directory (`.next`).
5. Click **Deploy**! 🚀
